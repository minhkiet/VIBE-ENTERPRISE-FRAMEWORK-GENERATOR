# Superpowers Plugin for Vibe Enterprise Framework

> Integrated from [obra/superpowers](https://github.com/obra/superpowers) (v7.0.2).

## Overview

Superpowers is a complete software development methodology for AI coding assistants. It enforces:
1. **Brainstorming** before building anything
2. **Git Worktrees** for branch and environment isolation
3. **Writing Plans** for small, atomic tasks (2-5 minutes each)
4. **Subagent-Driven Development** or **Executing Plans** with two-stage reviews
5. **Test-Driven Development (TDD)**: RED-GREEN-REFACTOR cycle
6. **Systematic Debugging**: 4-phase root cause analysis
7. **Verification Before Completion**: Evidence over claims
8. **Diagnosing Superpowers**: Transcript analysis and telemetry
